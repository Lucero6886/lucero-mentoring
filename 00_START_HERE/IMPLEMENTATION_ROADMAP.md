# Implementation Roadmap

## Phase 0 - Chốt nguồn chuẩn
- Chỉ định `06_Data/` là dữ liệu chuẩn cho danh mục, rubric và milestone.
- Mọi thay đổi cấu trúc đề tài phải cập nhật dữ liệu chuẩn trước rồi mới sinh lại catalog.
- Không lưu dữ liệu cá nhân sinh viên trong repository công khai.

## Phase 1 - Chuẩn bị cohort
- Công bố catalog phù hợp (P/I/T/R), không công bố toàn bộ internal research roadmap nếu không cần.
- Sinh viên nộp Top 3 nguyện vọng + self-assessment.
- Thực hiện readiness test 2 tuần: literature + technical mini-task + oral check.
- Mentor quyết định: nhận / nhận có điều kiện / đổi scope / chưa nhận.

## Phase 2 - Onboarding
- Ký working agreement.
- Tạo repository/thư mục project từ `04_Project_Template/`.
- Chốt MVT (Minimum Viable Thesis/Project) và Research Extension riêng.
- Lập milestone và evidence expectations.

## Phase 3 - Vận hành hàng tuần
- Sinh viên gửi weekly report trước meeting.
- Meeting ưu tiên evidence, blocker, decision, next step; không dùng để hỏi “em làm gì tiếp?”.
- Mỗi quyết định phải được ghi lại trong tracker/repository.
- Mentor phân thời gian: common mentoring > theme mentoring > individual mentoring.

## Phase 4 - Gate review
- Gate 1: problem/foundation.
- Gate 2: baseline.
- Gate 3: core implementation; nếu chậm -> reduce scope.
- Gate 4: experiments; đóng cửa thêm thuật toán lớn.
- Gate 5: analysis/draft.
- Gate 6: reproducibility/defense/legacy.

## Phase 5 - Closeout
- Kiểm tra ownership, reproducibility, academic integrity.
- Hoàn tất Project Legacy Package.
- Ghi `known_issues` và `next_steps` để cohort sau kế thừa.
- Chỉ những sinh viên đáp ứng Research Readiness mới được mời tiếp tục NCKH.
